## 이 장의 목표와 큰 그림

선형회귀(Linear Regression)는 입력과 출력 사이의 관계를 **직선 하나**로 나타내는 방법입니다. 공부 시간으로 시험 점수를, 물고기 길이로 무게를, 방 수와 위치 정보로 집값을 예측합니다.

이 장이 중요한 까닭은 직선 하나를 맞추는 과정에 딥러닝 학습의 뼈대가 모두 들어 있기 때문입니다.

1. **가설**(Hypothesis) — 예측하는 식을 정합니다. `$H(x) = Wx + b$`
2. **손실**(Loss, Cost) — 예측이 얼마나 틀렸는지 숫자 하나로 잽니다.
3. **경사하강법**(Gradient Descent) — 손실이 줄어드는 방향으로 `$W$`와 `$b$`를 조금씩 옮깁니다.
4. **여러 입력** — 입력이 여러 개여도 행렬곱 한 번으로 같은 계산을 합니다.

3장의 분류, 4장의 MLP, 5장의 CNN은 이 중 **가설만 바꾸고** 나머지는 그대로 씁니다.

## 강의 2-1 회귀란 무엇인가

**회귀**(regression)는 연속된 숫자를 예측하는 문제입니다. 강의는 공부 시간으로 시험 점수를 예측하는 예로 시작합니다.

| 공부 시간 X(hours) | 점수 Y(score) |
|---|---|
| 10 | 90 |
| 9 | 80 |
| 3 | 50 |
| 2 | 30 |

이미 알고 있는 (X, Y) 쌍으로 관계를 배운 뒤, 처음 보는 X에 대해 Y를 내놓는 것이 목표입니다. 예측값이 "합격/불합격"처럼 몇 개의 범주 가운데 하나이면 3장의 **분류**가 됩니다.

원리를 보기 쉽게 하려고 강의는 더 단순한 데이터를 씁니다. 점 세 개 (1, 1), (2, 2), (3, 3)입니다. 2장 실습 2-1·2-2·2-3도 이 세 점에서 출발합니다.

## 강의 2-1 가설과 손실함수

### 가설: 직선으로 예측한다

**가설**(Hypothesis)은 입력으로 예측값을 만드는 식입니다. 선형회귀의 가설은 직선입니다.

```math
H(x) = Wx + b
```

- `$W$` — 가중치(weight). 직선의 기울기
- `$b$` — 편향(bias). 직선의 절편

`$W$`와 `$b$`를 바꾸면 다른 직선이 됩니다. 강의 슬라이드 4–6은 세 점 위에 직선 세 개를 그려 놓고 "어떤 가설이 가장 좋은가?"를 묻습니다.

⟪fig:ch02_hypotheses|그림 2-2 · 같은 세 점에 서로 다른 세 직선. 세로선이 각 점의 오차이고, 오차가 작을수록 MSE가 작습니다.⟫

### 손실함수: 틀린 정도를 숫자 하나로

사람은 그림을 보고 "가운데가 낫다"고 말할 수 있지만 컴퓨터는 숫자가 필요합니다. 각 점에서 **예측값 − 실제값**을 구하고, 이를 제곱해서 평균을 냅니다.

```math
cost(W, b) = \frac{1}{m} \sum_{i=1}^{m} \left( H(x^{(i)}) - y^{(i)} \right)^2
```

- `$m$` — 데이터 개수
- `$x^{(i)}, y^{(i)}$` — `$i$`번째 데이터의 입력과 실제값
- 제곱하는 까닭: 오차가 +와 −로 섞여도 서로 지워지지 않게 하고, 큰 오차를 더 크게 벌주기 위해서입니다.

이 값을 **평균제곱오차**(MSE, Mean Squared Error)라고 부릅니다. 강의는 Loss와 Cost를 같은 뜻으로 씁니다.

⟪box:궁극적인 목적⟫

학습이란 **cost(W, b)를 가장 작게 만드는 W와 b를 찾는 일**입니다. 이 문장이 강의 2-1의 결론이며, 강의 2-2는 그 방법(경사하강법)을 다룹니다.

⟪/box⟫

## 실습 2-1 학습 함수 만들기

이제 `$W$`와 `$b$`를 0에서 시작해 **자동으로** 맞춥니다. 학습은 네 단계를 반복합니다.

| 단계 | 코드 | 의미 |
|---|---|---|
| Forward(순전파) | `prediction = W * x + b` | 예측값 계산 |
| Loss(손실) | `loss = ((prediction - y) ** 2).mean()` | 예측 오차 계산 |
| Backward(역전파) | `loss.backward()` | `W`, `b`의 기울기 계산 |
| Update(갱신) | `optimizer.step()` | `W`, `b` 갱신 |

갱신 규칙은 한 줄입니다. 이 식이 왜 맞는지는 강의 2-2에서 유도합니다.

```math
\text{새 매개변수} = \text{현재 매개변수} - \text{학습률} \times \text{기울기}
```

**SGD**(Stochastic Gradient Descent, 확률적 경사하강법)는 이 규칙을 그대로 실행하는 PyTorch의 최적화 도구입니다.

⟪code:ch02_1_linear_forward_and_loss:05⟫

⟪box:코드 풀이⟫

- `requires_grad=True` — 1장 자동 미분에서 본 설정입니다. 이 값으로 계산한 Loss에 `backward()`를 하면 `W.grad`, `b.grad`가 채워집니다.
- `torch.optim.SGD([W, b], lr=learning_rate)` — 학습할 값 목록과 학습률을 넘깁니다. `step()`을 부르면 `W ← W − lr × W.grad`를 실행합니다.
- `optimizer.zero_grad()` — PyTorch는 기울기를 **더해 쌓습니다.** 매 반복 처음에 비우지 않으면 이전 반복의 기울기가 섞입니다.
- `return W.detach(), ...` — 학습이 끝난 값을 기울기 계산 기록에서 떼어 내 돌려줍니다.
- 이 함수는 정의만 하므로 실행 결과가 없습니다.

## 강의 2-2 가설을 간소화해서 비용 곡선 보기

강의 2-2는 "손실을 어떻게 최소화하는가"를 다룹니다. 원리를 보기 쉽게 편향 `$b$`를 잠시 빼고 가중치 하나만 남깁니다.

```math
H(x) = Wx \qquad cost(W) = \frac{1}{m}\sum_{i=1}^{m}\left(Wx^{(i)} - y^{(i)}\right)^2
```

편향이 필요 없다는 뜻이 아닙니다. `$W$` 하나가 움직이는 모습만 보려는 단순화입니다. 세 점 (1,1), (2,2), (3,3)으로 `$W$`마다 비용을 계산합니다.

| W | 계산 | cost |
|---|---|---|
| 1 | `$\frac{1}{3}[(1-1)^2 + (2-2)^2 + (3-3)^2]$` | 0 |
| 0 | `$\frac{1}{3}[(0-1)^2 + (0-2)^2 + (0-3)^2] = \frac{14}{3}$` | ≈ 4.67 |
| 2 | `$\frac{1}{3}[(2-1)^2 + (4-2)^2 + (6-3)^2] = \frac{14}{3}$` | ≈ 4.67 |

여러 `$W$`에서 계산해 이으면 `$W = 1$`이 가장 낮은 **포물선**(그릇 모양)이 됩니다. 이 데이터에서는 식을 정리하면 다음과 같습니다.

```math
cost(W) = \frac{14}{3}(W - 1)^2
```

## 강의 2-2 경사하강법의 원리

**경사하강법**(Gradient Descent)은 비용을 최소화하는 일반적인 방법입니다. `cost(W, b)`를 가장 작게 하는 `$W$`, `$b$`를 찾고, 선형회귀보다 복잡한 함수에도 그대로 쓰입니다.

동작 원리는 산에서 눈을 감고 내려가는 것과 같습니다.

1. 초기값으로 시작합니다. (0, 0)이든 다른 값이든 괜찮습니다.
2. 지금 위치에서 비용을 가장 많이 줄이는 경사(기울기)를 봅니다.
3. 그 방향으로 `$W$`, `$b$`를 조금 옮깁니다.
4. 최솟값에 도착할 때까지 반복합니다.

- **기울기 > 0** — 오른쪽으로 갈수록 비용이 커집니다. `$W$`를 줄입니다.
- **기울기 < 0** — 오른쪽으로 갈수록 비용이 작아집니다. `$W$`를 늘립니다.
- **기울기 ≈ 0** — 바닥 근처입니다.

⟪fig:ch02_cost_path|그림 2-4 · 비용 곡선 위의 경사하강법. W = 5에서 시작해 학습률 0.1로 다섯 번 만에 W = 1에 거의 도착합니다.⟫

⟪box:주의: 지역 최솟값⟫

강의는 "어디서 시작하느냐에 따라 도달하는 최솟값이 달라질 수 있다"고 강조합니다. 슬라이드 29의 왼쪽 곡면처럼 골짜기가 여러 개이면 가까운 골짜기(**지역 최솟값**, local minimum)에 멈출 수 있습니다.

선형회귀의 MSE는 오른쪽 곡면처럼 **그릇이 하나**(볼록, convex)이므로 어디서 시작해도 같은 최솟값에 도착합니다. 4장의 MLP부터는 골짜기가 여러 개인 경우를 다룹니다.

⟪/box⟫

## 강의 2-2 갱신식 유도

강의는 미분을 편하게 하려고 비용 앞의 `$\frac{1}{m}$`을 `$\frac{1}{2m}$`으로 바꿉니다. 상수배는 최솟값의 위치를 바꾸지 않습니다.

```math
cost(W) = \frac{1}{2m}\sum_{i=1}^{m}\left(Wx^{(i)} - y^{(i)}\right)^2
```

갱신식은 "지금 W에서 학습률 `$\alpha$` × 기울기만큼 뺀다"입니다.

```math
W := W - \alpha \frac{\partial}{\partial W} cost(W)
```

미분을 계산합니다. `$(Wx - y)^2$`을 `$W$`로 미분하면 `$2(Wx - y)x$`이고, 앞의 `$\frac{1}{2m}$`의 2와 약분됩니다.

```math
W := W - \alpha \frac{1}{2m}\sum_{i=1}^{m} 2\left(Wx^{(i)} - y^{(i)}\right)x^{(i)}
= W - \alpha \frac{1}{m}\sum_{i=1}^{m}\left(Wx^{(i)} - y^{(i)}\right)x^{(i)}
```

마지막 식이 **경사하강법 알고리즘**입니다. 실습의 `loss.backward()`와 `optimizer.step()`은 이 계산을 자동으로 합니다.

⟪box:강의식과 실습식의 차이 (1/2m과 1/m)⟫

실습 2-3은 비용을 `$\frac{1}{m}$`로 정의하므로 기울기가 `$\frac{2}{m}\sum(Wx_i - y_i)x_i$`이고, 강의식(`$\frac{1}{m}\sum$`)의 **정확히 두 배**입니다. 최솟값의 위치(W = 1)는 같고, 같은 학습률로는 실습 쪽이 두 배 크게 움직입니다. 아래는 원본에 없는 **추가 확인** 코드입니다.

## 실습 2-4 실제 단위의 회귀식

모델은 표준화된 길이를 입력받습니다.

```math
\hat{y} = W_{scaled}\left(\frac{x - \mu}{\sigma}\right) + b_{scaled}
```

괄호를 풀면 cm와 g 단위의 직선이 됩니다.

```math
\hat{y} = \underbrace{\frac{W_{scaled}}{\sigma}}_{W_{real}} x + \underbrace{\left(b_{scaled} - \frac{W_{scaled}\,\mu}{\sigma}\right)}_{b_{real}}
```

이 변환은 결과를 실제 단위로 **해석하기 위한** 계산입니다. 예측할 때는 표준화한 입력을 모델에 넣으면 됩니다.

세 가지 지표를 함께 봅니다.

| 지표 | 식 | 해석 |
|---|---|---|
| MAE | `$\frac{1}{n}\sum \lvert y_i - \hat{y}_i \rvert$` | 평균적으로 몇 g 틀리는지 |
| RMSE | `$\sqrt{\frac{1}{n}\sum (y_i - \hat{y}_i)^2}$` | 큰 오차에 더 민감 |
| R² | `$1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}$` | 1에 가까울수록 실제값의 변화를 잘 설명 |

R²의 분모는 "평균 하나로만 예측했을 때의 오차"입니다. R² = 0.9이면 평균으로 찍는 것보다 오차(제곱합)를 90% 줄였다는 뜻입니다.

## 강의 2-3 여러 입력의 가설과 손실함수

지금까지는 입력이 하나였습니다. 강의 2-3은 입력이 여러 개인 **다중 선형회귀**(Multi-variable Linear Regression)를 다룹니다. 예는 퀴즈 두 번과 중간고사 점수로 기말 점수를 예측하는 것입니다.

| 학생 | `$x_1$` Quiz 1 | `$x_2$` Quiz 2 | `$x_3$` Midterm | `$y$` Final |
|---|---|---|---|---|
| 1 | 73 | 80 | 75 | 152 |
| 2 | 93 | 88 | 93 | 185 |
| 3 | 89 | 91 | 90 | 180 |
| 4 | 96 | 98 | 100 | 196 |
| 5 | 73 | 66 | 70 | 142 |

입력이 세 개이면 가중치도 세 개입니다.

```math
H(x_1, x_2, x_3) = w_1x_1 + w_2x_2 + w_3x_3 + b
```

손실함수는 모양이 같습니다. 예측값을 만드는 식만 바뀌었습니다.

```math
cost(W, b) = \frac{1}{m}\sum_{i=1}^{m}\left(H(x_1^{(i)}, x_2^{(i)}, x_3^{(i)}) - y^{(i)}\right)^2
```

입력이 `$n$`개이면 `$H = w_1x_1 + w_2x_2 + \dots + w_nx_n + b$`입니다. 입력이 100개, 1,000개가 되면 이렇게 하나하나 쓰기 어렵습니다. 그래서 **행렬**을 씁니다.

## 강의 2-3 행렬로 쓴 가설

`$w_1x_1 + w_2x_2 + w_3x_3$`은 가로 한 줄 `$(x_1\ x_2\ x_3)$`과 세로 한 줄 `$(w_1, w_2, w_3)$`의 **행렬곱**입니다(1장의 `@`). 학생 다섯 명을 한 행씩 쌓으면 한 번의 곱셈으로 다섯 명의 예측이 모두 나옵니다.

```math
\begin{pmatrix} x_{11} & x_{12} & x_{13} \\ x_{21} & x_{22} & x_{23} \\ \vdots & \vdots & \vdots \\ x_{51} & x_{52} & x_{53} \end{pmatrix}
\begin{pmatrix} w_1 \\ w_2 \\ w_3 \end{pmatrix}
=
\begin{pmatrix} x_{11}w_1 + x_{12}w_2 + x_{13}w_3 \\ x_{21}w_1 + x_{22}w_2 + x_{23}w_3 \\ \vdots \\ x_{51}w_1 + x_{52}w_2 + x_{53}w_3 \end{pmatrix}
\qquad H(X) = XW
```

⟪fig:ch02_matrix|그림 2-7 · 행렬로 쓴 가설. [5, 3] 입력과 [3, 1] 가중치를 곱하면 다섯 명의 예측 [5, 1]이 한 번에 나옵니다.⟫

### 모양 맞추기

강의 슬라이드 42–44는 빈칸 퀴즈입니다. 규칙은 두 가지입니다.

- 앞 행렬의 **열 수** = 뒤 행렬의 **행 수**
- 결과 모양 = [앞의 행 수, 뒤의 열 수]

| 입력 X | 가중치 W | 결과 H(X) | 의미 |
|---|---|---|---|
| [5, 3] | **[3, 1]** | [5, 1] | 학생 5명, 특성 3개 → 예측 1개씩 |
| [n, 3] | **[3, 1]** | [n, 1] | 학생 수 `$n$`이 몇이든 W는 그대로 |
| [n, 3] | **[3, 2]** | [n, 2] | 출력을 2개로 늘리려면 W의 열을 2개로 |

학생 수 `$n$`은 W의 모양에 영향을 주지 않습니다. 그래서 한 번 학습한 모델에 학생 몇 명이든 넣을 수 있습니다. 퀴즈의 정답과, 모양이 맞지 않을 때의 오류를 **추가 확인** 코드로 실행했습니다.

### WX와 XW

강의 이론은 `$H(x) = Wx + b$`로 쓰고, 구현은 `$H(X) = XW$`로 씁니다. 데이터를 **행 = 샘플**로 쌓으면 X가 앞에 오는 편이 자연스럽기 때문입니다. 계산하는 내용은 같습니다.

⟪box:nn.Linear는 어느 쪽인가⟫

`nn.Linear(입력 수, 출력 수)`는 `$XW^{T} + b$`를 계산합니다. weight를 **[출력 수, 입력 수]** 모양으로 저장하고 곱할 때 전치(T)합니다. 그래서 실습 2-2의 weight가 `[1, 1]`, 실습 2-5의 `nn.Linear(3, 1)`은 weight가 `[1, 3]`입니다. 강의 그림의 `[3, 1]`을 옆으로 눕힌 모양입니다.

## 실습 2-6 잔차 확인

**잔차**(Residual)는 실제값에서 예측값을 뺀 값입니다.

```math
Residual = y - \hat{y}
```

| 잔차 | 뜻 |
|---|---|
| 0에 가까움 | 예측이 정확함 |
| 양수 | 실제 가격보다 **낮게** 예측 |
| 음수 | 실제 가격보다 **높게** 예측 |
| 특정 모양이 반복됨 | 직선 모델이 설명하지 못한 관계가 있을 수 있음 |

⟪code:ch02_6_housing_price_prediction:13⟫

잔차가 0 주변에 위아래 고르게 흩어져 있으면 좋습니다. 이 그래프는 대부분 ±6 안에 있지만, 10을 넘는 **큰 양수 잔차**가 여러 개이고 그만큼 큰 음수는 하나뿐입니다. 비싼 집을 낮게 예측하는 경향이 남아 있다는 뜻입니다. 앞의 실제값–예측값 그래프에서 실제 가격 50인 집들(오른쪽 끝 세로 줄)이 모두 대각선 아래에 있는 것과 같은 현상입니다.

⟪box:실제 가격 50의 의미⟫

이 데이터의 MEDV 최댓값은 50.0이고 506개 중 16개가 정확히 50.0입니다. 50 이상의 값을 50으로 잘라 기록한 데이터로 알려져 있습니다. 실제로는 더 비쌀 수 있는 집이 50으로 적혀 있으므로, 이 구간의 큰 잔차를 모델 탓으로만 보면 안 됩니다. 데이터 자체의 성질도 함께 봅니다.

## 정리와 스스로 점검

| 주제 | 핵심 | 다음에 쓰는 곳 |
|---|---|---|
| 가설 | `$H(x) = Wx + b$`, 여러 입력은 `$H(X) = XW + b$` | 3장 시그모이드·소프트맥스 앞단 |
| 손실 | MSE = 오차 제곱의 평균 | 3장은 교차 엔트로피로 바뀜 |
| 경사하강법 | `$W := W - \alpha\, \partial cost / \partial W$` | 모든 장 |
| 학습률 | 작으면 느림, 크면 발산. 경계는 데이터마다 다름 | 4장 옵티마이저 선택 |
| 학습 반복 | 순전파 → 손실 → zero_grad → backward → step | 모든 장 |
| 데이터 준비 | 섞어서 분리, 훈련 통계로만 표준화 | 3·4·5장 |
| 평가 | MAE·RMSE·R², 훈련과 테스트 비교, 잔차 | 4장 과적합 |
| 한계 | 직선은 휘어진 관계를 못 배움, 외삽 주의 | 4장 MLP |
