## 1-1 배열과 텐서 만들기

같은 리스트 `[1, 2, 3, 4]`를 NumPy 배열과 PyTorch 텐서로 각각 만듭니다.

## 1-1 shape · 인덱싱 · reshape

- **shape**(셰이프) — 데이터의 모양입니다. `(2, 3)`은 2행 3열입니다.
- **인덱스**는 0부터 셉니다. `[0, 1]`은 첫 번째 행의 두 번째 열입니다.
- **reshape** — 값과 개수는 그대로 두고 모양만 바꿉니다. 원소가 6개이면 `(3, 2)`, `(1, 6)`, `(6, 1)`로 바꿀 수 있습니다.

```python
# 2행 3열 데이터
data = [[1, 2, 3],
        [4, 5, 6]]

np_matrix = np.array(data)
torch_matrix = torch.tensor(data)

print("NumPy shape :", np_matrix.shape)
print("PyTorch shape:", torch_matrix.shape)

# 첫 번째 행, 두 번째 열의 값
print("NumPy 값 :", np_matrix[0, 1])
print("PyTorch 값:", torch_matrix[0, 1])

# 2행 3열을 3행 2열로 변경
print("\nNumPy reshape")
print(np_matrix.reshape(3, 2))

print("\nPyTorch reshape")
print(torch_matrix.reshape(3, 2))
```

## 1-1 원소별 곱셈과 행렬곱

곱셈 기호는 두 가지이고 결과가 다릅니다. 반드시 구분합니다.

- `*` — **원소별 곱셈**: 같은 위치의 원소끼리 곱합니다.
- `@` — **행렬곱**: 앞 행렬의 행과 뒤 행렬의 열을 곱해서 더합니다.

⟪fig:ch01_mul|그림 1-2 · 같은 두 행렬이라도 *와 @의 결과가 다릅니다. 노란 칸은 결과의 한 칸이 어떤 값에서 나오는지 보여 줍니다.⟫

코드 박스: code/ch01_1_numpy_torch.py · CODE 05 · 실행 확인

```python
a_np = np.array([[1, 2],
                 [3, 4]])

b_np = np.array([[5, 6],
                 [7, 8]])

a_torch = torch.tensor(a_np)
b_torch = torch.tensor(b_np)

# 원소별 곱셈: 같은 위치의 원소끼리 곱합니다.
print("NumPy 원소별 곱셈")
print(a_np * b_np)

print("\nPyTorch 원소별 곱셈")
print(a_torch * b_torch)

# 행렬곱: 행과 열을 곱하여 새로운 행렬을 만듭니다.
print("\nNumPy 행렬곱")
print(a_np @ b_np)

print("\nPyTorch 행렬곱")
print(a_torch @ b_torch)
```

- 원소별 곱: `[[1×5, 2×6], [3×7, 4×8]] = [[5, 12], [21, 32]]`

## 1-1 NumPy와 PyTorch 사이의 변환

데이터는 보통 NumPy로 읽고 다듬은 뒤 텐서로 바꿔 모델에 넣습니다. 결과는 다시 NumPy로 바꿔 그래프로 그립니다.

```python
# PyTorch 텐서 → NumPy 배열
back_to_numpy = tensor_data.numpy().copy()

print("원본 NumPy :", np_data)
print("PyTorch 변환:", tensor_data)
print("다시 NumPy :", back_to_numpy)
```

`.copy()`를 붙이는 이유는 `.numpy()`가 텐서와 **메모리를 함께 쓰기** 때문입니다. 메모리 공유는 1-3의 메모리 공유 절에서 그림과 함께 자세히 봅니다.

## 1-1 자동 미분

함수 `$y = x^2 + 2x$`를 미분하면 다음과 같습니다.

```math
\frac{dy}{dx} = 2x + 2
```

`$x = 3$`을 넣으면 기울기는 `$2 \times 3 + 2 = 8$`입니다. PyTorch는 이 값을 `backward()` 한 번으로 계산합니다. 이것이 **Autograd**(오토그래드, 자동 미분)입니다.

⟪fig:ch01_autograd|그림 1-3 · 순전파에서 계산 과정을 기록하고, backward()가 그 기록을 거꾸로 따라가며 기울기를 구합니다.⟫

코드 박스: code/ch01_1_numpy_torch.py · CODE 07 · 실행 확인

```python
# x에 대한 계산 과정을 추적하도록 설정합니다.
x = torch.tensor(3.0, requires_grad=True)
# y = x² + 2x
y = x**2 + 2*x
# y를 x로 미분합니다.
y.backward()
print("x =", x.item())
print("y =", y.item())
print("dy/dx =", x.grad.item())
```

실행 결과: CODE 07 · Python 3.13.18 · NumPy 2.5.3 · PyTorch 2.15.0+cpu(CPU)에서 실행

```text
x = 3.0
y = 15.0
dy/dx = 8.0
```


⟪box:코드 풀이⟫

- `requires_grad=True` — "이 값에 대한 기울기가 필요하다"고 표시합니다. 이후 계산 과정이 기록됩니다.
- `y.backward()` — 기록을 거꾸로 따라가 `$dy/dx$`를 구해 `x.grad`에 넣습니다.
- `.item()` — 값 하나짜리 텐서에서 숫자를 꺼냅니다.
- 손으로 구한 8과 같습니다. 2장에서는 `$x$` 자리에 가중치 `$W$`, `$y$` 자리에 손실(cost)을 두고 똑같이 기울기를 구합니다.

⟪/box⟫

## 1-1 미니 실습: 센서 데이터 정규화

센서값 `[20, 30, 40, 50]`을 0~1 범위로 바꿉니다. 이를 **최소-최대 정규화**라고 합니다.

```math
x_{\text{norm}} = \frac{x - x_{\min}}{x_{\max} - x_{\min}}
```

단위가 다른 값을 같은 범위로 맞추면 학습이 안정됩니다. 2장 집값 예측에서는 같은 목적으로 평균 0·표준편차 1로 맞추는 **표준화**를 씁니다.

코드 박스: code/ch01_1_numpy_torch.py · CODE 08 · 실행 확인

```python
# 센서 측정값을 0~1 범위로 변환합니다.
sensor_values = [20.0, 30.0, 40.0, 50.0]

# NumPy
np_sensor = np.array(sensor_values, dtype=np.float32)
np_normalized = (np_sensor - np_sensor.min()) / (np_sensor.max() - np_sensor.min())

# PyTorch
torch_sensor = torch.tensor(sensor_values, dtype=torch.float32)
torch_normalized = (
    (torch_sensor - torch_sensor.min())
    / (torch_sensor.max() - torch_sensor.min())
)

print("NumPy 결과 :", np_normalized)
print("PyTorch 결과:", torch_normalized)

# 두 결과가 같은지 확인합니다.
print("결과 일치:", np.allclose(np_normalized, torch_normalized.numpy()))
```

실행 결과: CODE 08 · Python 3.13.18 · NumPy 2.5.3 · PyTorch 2.15.0+cpu(CPU)에서 실행

```text
NumPy 결과 : [0.         0.33333334 0.6666667  1.        ]
PyTorch 결과: tensor([0.0000, 0.3333, 0.6667, 1.0000])
결과 일치: True
```


⟪box:코드 풀이⟫

- `np_sensor - np_sensor.min()`은 배열에서 숫자 하나를 빼는 계산입니다. 1-2의 브로드캐스팅이 이 일을 합니다.
- `np.allclose()`는 두 결과가 오차 범위 안에서 같은지 확인합니다. 실수 계산은 마지막 자리가 조금 다를 수 있어 `==` 대신 씁니다.

⟪/box⟫

## 1-2 차원과 모양: 스칼라·벡터·행렬·텐서

| 구분 | 의미 | 예시 shape |
|---|---|---|
| Scalar(스칼라) | 값 1개 | `()` |
| Vector(벡터) | 1차원 데이터 | `(3,)` |
| Matrix(매트릭스) | 2차원 데이터 | `(2, 2)` |
| Tensor(텐서) | 3차원 이상까지 포함한 다차원 데이터 | `(2, 3, 4)` |

- **ndim** — 차원의 개수입니다.
- **shape** — 각 차원에 값이 몇 개 있는지 적은 것입니다.

## 1-3 메모리 공유와 복사

`torch.from_numpy()`로 만든 Tensor는 원본 배열과 **메모리를 공유**합니다. 배열 값을 바꾸면 Tensor 값도 바뀝니다. 독립된 복사본이 필요하면 `clone()`을 씁니다.

```python
copied_tensor = shared_tensor.clone()

# NumPy 배열의 첫 번째 값을 변경합니다.
numpy_data[0, 0] = 99

print("변경된 NumPy 배열:")
print(numpy_data)

print()
print("메모리를 공유하는 Tensor:")
print(shared_tensor)

print()
print("미리 복사한 독립 Tensor:")
print(copied_tensor)
```

실행 결과: CODE 03 · Python 3.13.18 · NumPy 2.5.3 · PyTorch 2.15.0+cpu(CPU)에서 실행

```text
 [30. 40.]]
```

```python
t_copy = torch.tensor(arr)        # 새 메모리에 복사
t_share = torch.from_numpy(arr)   # arr 과 같은 메모리
arr[0] = 100.0
print("arr          :", arr)
print("torch.tensor :", t_copy)
print("from_numpy   :", t_share)

back = t_copy.numpy()             # 텐서 → 배열도 메모리 공유
t_copy[1] = -1.0
print("t_copy.numpy():", back)
```

⟪box:꼭 기억할 점⟫

| 메모리를 함께 씀 | 새로 복사함 |
|---|---|
| `torch.from_numpy(arr)` | `torch.tensor(arr)` |
| `tensor.numpy()` | `tensor.clone()` |
| | `array.copy()` |

공유는 메모리를 아끼지만, 한쪽을 바꾸면 다른 쪽도 바뀝니다. 헷갈리면 복사하는 쪽을 씁니다.

⟪/box⟫

## 1-3 모양 바꾸기: reshape와 flatten

`reshape()`는 원소의 총개수를 유지하면서 모양을 바꿉니다. `$2 \times 3 = 3 \times 2 = 6$`이므로 원소 6개는 `(2, 3)`, `(3, 2)`, `(1, 6)`이 될 수 있습니다. `flatten()`은 여러 차원을 1차원으로 펼칩니다.

코드 박스: code/ch01_3_tensor_operations.py · CODE 05 · 실행 확인

```python

print("원래 Tensor:")
print(tensor_a)
print("shape:", tensor_a.shape)

print()
print("reshape(3, 2):")
print(tensor_a.reshape(3, 2))

print()
print("flatten():")
print(tensor_a.flatten())
```

## 1-3 cat과 stack

두 Tensor를 합치는 방법은 두 가지입니다.

| 함수 | 핵심 동작 | `(2, 3)` 두 개의 결과 |
|---|---|---|
| `torch.cat()` | 기존 차원을 따라 연결 | dim=0 → `(4, 3)`, dim=1 → `(2, 6)` |
| `torch.stack()` | 새 차원을 만들어 쌓기 | dim=0 → `(2, 2, 3)` |

⟪fig:ch01_cat_stack|그림 1-7 · cat은 표를 이어 크게 만들고, stack은 표를 겹쳐 묶음 차원을 새로 만듭니다.⟫

`dim`은 "행·열"이라는 이름보다 **어느 차원의 크기가 늘어나는가**로 기억하는 것이 좋습니다.

코드 박스: code/ch01_3_tensor_operations.py · CODE 06 · 실행 확인

```python
tensor_b = torch.tensor(
    [[10, 20, 30],
     [40, 50, 60]]
)

cat_dim0 = torch.cat([tensor_a, tensor_b], dim=0)
cat_dim1 = torch.cat([tensor_a, tensor_b], dim=1)

print("cat dim=0:")
print(cat_dim0)
print("shape:", cat_dim0.shape)

print()
print("cat dim=1:")
print(cat_dim1)
print("shape:", cat_dim1.shape)
```

```text
        [ 4,  5,  6, 40, 50, 60]])

```


코드 박스: code/ch01_3_tensor_operations.py · CODE 07 · 실행 확인

## 1-3 미니 실습: 측정 묶음 합치기

두 번에 나눠 측정한 온도·진동 데이터를 합칩니다. 각 행은 측정 한 번, 첫 번째 열은 온도, 두 번째 열은 진동입니다.

코드 박스: code/ch01_3_tensor_operations.py · CODE 08 · 실행 확인

```python
# 첫 번째 측정 묶음
batch_1 = torch.tensor(
    [[22.0, 0.10],
     [25.0, 0.15]]
)

# 두 번째 측정 묶음
batch_2 = torch.tensor(
    [[31.0, 0.45],
     [36.0, 0.90]]
)

# 모든 측정값을 하나의 표로 연결합니다.
all_sensor_data = torch.cat([batch_1, batch_2], dim=0)

# 두 측정 묶음을 구분한 상태로 쌓습니다.
grouped_sensor_data = torch.stack([batch_1, batch_2], dim=0)

print("하나로 연결한 센서 데이터:")
print(all_sensor_data)
print("shape:", all_sensor_data.shape)

print()
print("측정 묶음별로 쌓은 센서 데이터:")
print(grouped_sensor_data)
print("shape:", grouped_sensor_data.shape)
```

실행 결과: CODE 08 · Python 3.13.18 · NumPy 2.5.3 · PyTorch 2.15.0+cpu(CPU)에서 실행

```text
하나로 연결한 센서 데이터:

        [25.0000,  0.1500],
        [31.0000,  0.4500],
        [36.0000,  0.9000]])
shape: torch.Size([4, 2])

측정 묶음별로 쌓은 센서 데이터:
tensor([[[22.0000,  0.1000],
         [25.0000,  0.1500]],

        [[31.0000,  0.4500],
         [36.0000,  0.9000]]])
shape: torch.Size([2, 2, 2])
```


⟪box:코드 풀이⟫

- `cat(dim=0)` → `(4, 2)`: 측정 네 번을 한 표로 이었습니다. 학습 데이터를 모을 때 씁니다.
- `stack(dim=0)` → `(2, 2, 2)`: 어느 묶음에서 나온 측정인지 구분한 채 쌓았습니다.

## 정리와 스스로 점검

| 주제 | 핵심 | 다음에 쓰는 곳 |
|---|---|---|
| 배열과 텐서 | NumPy는 `ndarray`, PyTorch는 `Tensor`. 문법은 거의 같음 | 전 과정 |
| 모양 | `shape`·`reshape`·`flatten`, 행 = 샘플 · 열 = 특징 | 2장 데이터, 4장 이미지 펼치기 |
| 곱셈 | `*`는 원소별, `@`는 행렬곱 | 2장 `X @ W + b` |
| 고르기 | 인덱싱 `[:, 0]`, 불리언 마스크 | 4장 오답 분석 |
| 변환 | `from_numpy`·`numpy()`는 공유, `tensor()`·`clone()`·`copy()`는 복사 | 데이터 준비 |
| 장치 | `device`, `.to(device)` | 4장 GPU 학습 |
| 자동 미분 | `requires_grad` → `backward()` → `.grad` | 2장 경사하강법 |

⟪box:스스로 점검⟫

1. shape가 `(4, 3)`인 배열의 ndim과 원소 개수는?
2. `[[1, 2], [3, 4]] * [[5, 6], [7, 8]]`과 `@`의 결과 첫 칸은 각각 얼마인가?
3. 배열 `arr`로 `t = torch.from_numpy(arr)`를 만든 뒤 `arr[0] = 0`을 하면 `t[0]`은?
4. `(2, 3)` 텐서 두 개를 `cat(dim=1)`, `stack(dim=0)` 하면 shape는?

정답: ① ndim 2, 원소 12개 ② 5와 19 ③ 0, 메모리를 공유하므로 ④ `(2, 6)`과 `(2, 2, 3)` ⑤ `$2 \times 1 + 2 = 4$`
