## 이 장의 목표와 큰 그림

- **풀링**(Pooling) — 2×2 영역을 하나로 줄여 크기를 절반으로 만듭니다.
- 이 둘을 두 번 거친 뒤에야 Flatten → Linear로 분류합니다. 뒷부분은 4장과 같습니다.

## 강의 5장 CNN 아키텍처

슬라이드 2는 4장에서 본 머신러닝 구조(입력층 → 출력층)와 딥러닝 구조(사이에 은닉층)를 다시 보여 줍니다. 슬라이드 3이 CNN 구조입니다.

```text
학습 데이터 → [conv → ReLU → pooling] → [conv → ReLU → pooling] → Flatten → Linear → softmax → 손실함수 최소?
                컨볼루션층 1              컨볼루션층 2              완전연결층      출력층
                (W2, b2)                  (W3, b3)                  (W4, b4)
```

- 앞의 **컨볼루션층**들이 이미지에서 특징을 뽑습니다(특징 추출기).
- 뒤의 **완전연결층**(Flatten + Linear)이 그 특징으로 클래스를 고릅니다(분류기). 4장의 MLP가 이 자리에 들어갑니다.
- 바깥 학습 고리는 2장부터 같습니다. 옵티마이저가 W2, b2, W3, b3, W4, b4를 모두 갱신하고 반복합니다. 즉 **필터도 학습 대상**입니다.

## 강의 5장 합성곱과 풀링

**합성곱**(Conv)은 입력 데이터와 가중치 묶음인 **필터**(filter)를 연산해 입력의 **특징**(feature)을 뽑아 다음 층으로 넘깁니다(슬라이드 4). 입력마다 필터와 바이어스가 따로 있습니다.

**풀링**(Pooling)은 영역의 값을 최댓값·최솟값·평균값 등으로 줄여 연산량을 줄입니다(슬라이드 5). 같은 2×2 영역 `[[15, 16], [6, 15]]`를 세 방법으로 줄여 봅니다(**추가 확인**).

```python
# 강의 슬라이드 5: 같은 2×2 영역을 세 가지 방법으로 줄이기
```

## 강의 5장 합성곱 연산과 특징 맵

필터를 일정한 간격(**스트라이드**)으로 옮기며, 입력과 필터에서 같은 자리끼리 곱한 뒤 모두 더합니다(슬라이드 6–7). 그 결과에 바이어스를 더한 것이 **특징 맵**(feature map)입니다.

⟪fig:ch05_conv|그림 5-2 · 강의 슬라이드 6의 예. 왼쪽 위 3×3(노란 칸)과 필터를 곱해 더하면 15이고, 바이어스 3을 더해 특징 맵 18이 됩니다.⟫

강의의 숫자를 그대로 넣어 손 계산과 PyTorch 결과를 비교했습니다(**추가 확인**). 이어서 ReLU(슬라이드 8)와 max pooling까지 적용합니다.

코드 박스: code/ch05_extra_checks.py · CODE 01 · 실행 확인

```python
# 강의 슬라이드 6·7: 4×4 입력과 3×3 필터의 합성곱 → 바이어스 → ReLU → 2×2 Max Pooling
import torch
import torch.nn.functional as F

x = torch.tensor([[1, 2, 3, 0],
                  [0, 1, 2, 3],
                  [3, 0, 1, 2],
                  [2, 3, 0, 1]], dtype=torch.float32)
w = torch.tensor([[2, 0, 1],
                  [0, 1, 2],
                  [1, 0, 2]], dtype=torch.float32)

# 손으로 하는 방법: 필터를 한 칸씩 옮기며 같은 자리끼리 곱해서 모두 더한다
manual = torch.zeros(2, 2)
for r in range(2):
    for c in range(2):
        manual[r, c] = (x[r:r + 3, c:c + 3] * w).sum()
print("손 계산 합성곱:\n", manual)

# PyTorch: 입력은 [N, C, H, W], 필터는 [출력 채널, 입력 채널, 높이, 너비]
torch_result = F.conv2d(x.view(1, 1, 4, 4), w.view(1, 1, 3, 3), bias=torch.tensor([3.0]))
print("F.conv2d + 바이어스 3:\n", torch_result[0, 0])
print("ReLU 뒤 :\n", F.relu(torch_result)[0, 0])
print("2×2 Max Pooling:", F.max_pool2d(F.relu(torch_result), 2).item())
```

실행 결과: CODE 01 · Python 3.13.18 · NumPy 2.5.3 · PyTorch 2.15.0+cpu(CPU)에서 실행

```text
손 계산 합성곱:
 tensor([[15., 16.],
        [ 6., 15.]])
F.conv2d + 바이어스 3:
 tensor([[18., 19.],
        [ 9., 18.]])
ReLU 뒤 :
 tensor([[18., 19.],
        [ 9., 18.]])
2×2 Max Pooling: 19.0
```


⟪box:코드 풀이⟫

- `x[r:r+3, c:c+3] * w` — 1장의 슬라이싱과 원소별 곱입니다. 3×3 창을 잘라 필터와 곱하고 `.sum()`으로 더합니다.
- `F.conv2d(입력, 필터)` — 입력은 `[N, C, H, W]`, 필터는 `[출력 채널, 입력 채널, 높이, 너비]` 모양이어야 해서 `view`로 4차원으로 만들었습니다.
- 수학의 "합성곱"은 필터를 뒤집어서 곱하지만, 딥러닝 라이브러리는 **뒤집지 않고** 곱합니다(정확한 이름은 교차상관). 필터를 어차피 학습으로 정하므로 결과적으로 차이가 없고, 강의의 손 계산도 뒤집지 않는 방식입니다.

⟪/box⟫

## 강의 5장 비선형 함수 ReLU와 패딩

**ReLU**는 4장과 같이 `$\max(0, x)$`입니다. 특징 맵의 음수를 0으로 만듭니다. 슬라이드 8의 특징 맵 `[[18, 19], [9, 18]]`은 모두 양수라 그대로이고, max pooling 결과는 19입니다.

**패딩**(padding)은 합성곱 전에 입력 가장자리에 값을 둘러 붙이는 것입니다(슬라이드 9). 보통 0을 붙이는 **제로 패딩**을 쓰며, 합성곱을 할 때마다 크기가 줄어드는 단점을 보완합니다.

- 패딩 없음: 4×4 입력 → 2×2 결과
- 패딩 1칸: 6×6으로 늘린 입력 → 4×4 결과(원래 크기 유지)

코드 박스: code/ch05_extra_checks.py · CODE 03 · 실행 확인

```python
# 강의 슬라이드 9: 제로 패딩 1칸을 두르면 4×4 입력에서 4×4 결과가 나온다
padded = F.conv2d(x.view(1, 1, 4, 4), w.view(1, 1, 3, 3), padding=1)
print("padding=1 결과 (4×4):\n", padded[0, 0])
```

슬라이드 9의 결과표 `[[7, 12, 10, 2], [4, 15, 16, 10], [10, 6, 15, 6], [8, 10, 4, 3]]`와 같습니다. 가운데 네 칸(15, 16, 6, 15)은 패딩이 없을 때의 결과와 같고, 가장자리 칸이 새로 생겼습니다. 패딩 덕분에 **가장자리 픽셀도 필터의 가운데에 놓여 계산에 충분히 참여**합니다.

## 강의 5장 특징 추출 과정

슬라이드 11–15는 같은 입력에 서로 다른 필터 세 개(가로·대각선·세로)를 적용합니다.

```text
입력 ∗ 필터 → 합성곱 결과 + 바이어스 → 특징 맵 → ReLU → 2×2 max pooling
```

- **가로 필터**는 가로 획이 있는 자리에서, **세로 필터**는 세로 획이 있는 자리에서 큰 값을 냅니다.
- 마지막 풀링 결과(2×2)를 보면 각 필터가 이미지의 어느 구역에서 반응했는지 알 수 있습니다.

슬라이드 15의 해석: **풀링 값이 클수록 그 영역에 필터가 찾는 특징이 강하게 있다**는 뜻입니다. 필터 하나가 "가로선 탐지기", "세로선 탐지기" 같은 역할을 합니다. 강의 예에서는 사람이 필터를 정했지만, CNN은 이런 필터를 **학습으로** 찾습니다. 실습 5-2에서 학습된 필터를 직접 봅니다.

## 강의 5장 Fashion-MNIST와 이미지 데이터

**Fashion-MNIST**는 MNIST의 영향을 받아 만든 의류·신발 이미지 데이터로, 같은 28×28 흑백 이미지 60,000 + 10,000장, 클래스 10개입니다(슬라이드 16). 손글씨보다 어려운 문제로 평가됩니다. 4장 실습 4-5에서 MLP로 이미 학습했습니다.

이미지는 **(높이, 너비, 채널)**의 3차원 텐서입니다(슬라이드 17).

- 흑백 이미지 — 채널 1개, 예: (28, 28, 1). 28×28짜리 판이 1장
- 컬러 이미지 — 채널 3개(빨강·초록·파랑), 예: (28, 28, 3). 28×28짜리 판이 3장

채널은 흔히 "색 성분"이라고 하지만, 딥러닝에서는 **서로 다른 판(데이터) 여러 장**이라고 이해하는 것이 더 정확합니다. 합성곱층의 출력 특징맵 8장도 채널 8개입니다. PyTorch는 순서를 바꿔 **[N, C, H, W]**(이미지 수, 채널, 높이, 너비)로 씁니다.

## 강의 5장 채널과 컨볼루션

입력 채널이 여러 개이면 필터 하나도 **입력 채널 수만큼의 판**을 가집니다(슬라이드 18).

1. 필터의 판 하나씩을 입력 채널 하나씩과 합성곱합니다.
2. 그렇게 나온 임시 특징맵들을 **모두 더해** 출력 채널 하나를 만듭니다.
3. 필터를 여러 개 두면 필터마다 출력 채널이 하나씩 생깁니다. **출력 채널 수 = 필터 수**입니다.

⟪fig:ch05_channels|그림 5-3 · 입력 채널이 둘일 때. 필터의 두 판을 각 채널에 적용한 결과를 더해 출력 채널 하나를 만듭니다.⟫

코드 박스: code/ch05_extra_checks.py · CODE 05 · 실행 확인

```python
# 강의 슬라이드 18: 입력 채널이 여러 개면 채널별 합성곱 결과를 더해 출력 채널 하나를 만든다
torch.manual_seed(0)
two_channel = torch.randn(1, 2, 5, 5)                 # 입력 채널 2개
conv = torch.nn.Conv2d(2, 1, kernel_size=3, bias=False)  # 필터 하나 = [1, 2, 3, 3]
whole = conv(two_channel)
per_channel = sum(
    F.conv2d(two_channel[:, k:k + 1], conv.weight[:, k:k + 1]) for k in range(2)
)
print("필터 모양 [출력, 입력, 높이, 너비]:", list(conv.weight.shape))
print("채널별 결과를 더한 값과 같은가?:", torch.allclose(whole, per_channel, atol=1e-6))
```

## 강의 5장 PyTorch CNN API와 모델

| 층 | PyTorch | 주요 인자 |
|---|---|---|
| 합성곱 | `nn.Conv2d(in_channels, out_channels, kernel_size, stride, padding)` | 입력 채널 수(흑백 1, 컬러 3), 출력 채널 수(= 필터 수), 필터 크기, 이동 간격, 패딩 |
| 풀링 | `nn.MaxPool2d(kernel_size=2, stride=2)` | 한 번에 줄일 영역 크기, 이동 간격 |
| 펼치기 | `nn.Flatten()` 또는 `x.view(-1, 벡터크기)` | 특징맵(채널, 높이, 너비)을 1차원 벡터로 바꿔 완전연결층에 연결 |

슬라이드 19–21의 모델이 실습 5-1의 모델입니다.

- `nn.Conv2d(1, 8, kernel_size=3, padding=1)` — 입력 채널 1개에서 3×3 필터 8개로 특징맵 8장. `padding=1`이라 28×28 유지
- `nn.ReLU()` — 음수를 0으로. 모양은 그대로
- `nn.MaxPool2d(kernel_size=2, stride=2)` — 2×2마다 최댓값 하나. 28×28 → 14×14
- `nn.Conv2d(8, 16, kernel_size=3, padding=1)` — 특징맵 8장을 받아 16장. 14×14 유지
- 두 번째 `MaxPool2d` — 14×14 → 7×7
- `nn.Flatten(start_dim=1)` — 배치 차원 N은 두고 `[16, 7, 7]`을 16×7×7 = 784개로 펼침
- `nn.Linear(16 * 7 * 7, 10)` — 784개 특징을 클래스 10개의 로짓으로

⟪fig:ch05_arch|그림 5-4 · 실습 5-1 CNN의 모양 변화와 층별 파라미터 수. 채널은 늘고 크기는 줄어듭니다.⟫

층별 파라미터를 세고 4장 실습 4-5의 MLP와 비교했습니다(**추가 확인**).

코드 박스: code/ch05_extra_checks.py · CODE 06 · 실행 확인

```python
# 실습 5-1 CNN과 실습 4-5 MLP의 층별 파라미터 수
from torch import nn

cnn = nn.Sequential(
    nn.Conv2d(1, 8, kernel_size=3, padding=1), nn.ReLU(), nn.MaxPool2d(2, 2),
    nn.Conv2d(8, 16, kernel_size=3, padding=1), nn.ReLU(), nn.MaxPool2d(2, 2),
    nn.Flatten(), nn.Linear(16 * 7 * 7, 10),
)
for name, parameter in cnn.named_parameters():
    print(f"CNN {name:<9} {str(list(parameter.shape)):<15} {parameter.numel():>7,}")
mlp_total = (784 * 256 + 256) + (256 * 128 + 128) + (128 * 10 + 10)
cnn_total = sum(p.numel() for p in cnn.parameters())
print(f"CNN 합계 {cnn_total:,} | MLP(실습 4-5) 합계 {mlp_total:,} | 비율 {mlp_total / cnn_total:.1f}배")
```

CNN의 파라미터는 9,098개로 MLP(235,146개)의 약 1/26입니다. 합성곱 필터의 파라미터는 **이미지 크기와 상관없이** 3×3×채널 수로 정해지기 때문입니다. 같은 필터를 이미지의 모든 위치에서 **다시 씁니다**(가중치 공유). MLP는 784개 입력 칸마다 가중치를 따로 둡니다.

## 강의 5장 패딩 · 스트라이드 · 필터 수

슬라이드 22–25는 출력 크기를 정하는 세 가지를 정리합니다.

```math
\text{출력 크기} = \left\lfloor \frac{N - F + 2P}{S} \right\rfloor + 1
```

`$N$`은 입력 크기, `$F$`는 필터 크기, `$P$`는 패딩, `$S$`는 스트라이드입니다.

⟪fig:ch05_pad_stride|그림 5-5 · 28×28 입력, 3×3 필터에서 패딩과 스트라이드에 따른 출력 크기.⟫

코드 박스: code/ch05_extra_checks.py · CODE 04 · 실행 확인

```python
image = torch.zeros(1, 1, 28, 28)
for padding in (0, 1):
    for stride in (1, 2):
        out = torch.nn.Conv2d(1, 1, kernel_size=3, padding=padding, stride=stride)(image)
        formula = (28 - 3 + 2 * padding) // stride + 1
        print(f"padding={padding}, stride={stride} → 실제 {tuple(out.shape[-2:])}, 식 {formula}×{formula}")
```

코드 박스: code/ch05_1_fashion_mnist_cnn_training_evaluation.py · CODE 13 · 실행 확인

```python
def train_one_epoch(
    model,
    data_loader
):
    model.train()

    loss_sum = 0.0
    correct = 0
    total = 0

    for images, labels in data_loader:
        images = images.to(device)
        labels = labels.to(device)

        optimizer.zero_grad()

        logits = model(images)

        loss = loss_function(
            logits,
            labels
        )

        loss.backward()
        optimizer.step()

        predictions = logits.argmax(
            dim=1
        )

        loss_sum += (
            loss.item()
            * images.size(0)
        )

        correct += (
            predictions == labels
        ).sum().item()

        total += labels.size(0)

    return (
        loss_sum / total,
        correct / total
    )
```


코드 박스: code/ch05_1_fashion_mnist_cnn_training_evaluation.py · CODE 14 · 실행 확인

```python
def evaluate_model(
    model,
    data_loader
):
    model.eval()

    loss_sum = 0.0
    correct = 0
    total = 0

    with torch.no_grad():
        for images, labels in data_loader:
            images = images.to(device)
            labels = labels.to(device)

            logits = model(images)

            loss = loss_function(
                logits,
                labels
            )

            predictions = logits.argmax(
                dim=1
            )

            loss_sum += (
                loss.item()
                * images.size(0)
            )

            correct += (
                predictions == labels
            ).sum().item()

            total += labels.size(0)

    return (
        loss_sum / total,
        correct / total
    )
```

```python
    1,
    NUMBER_OF_EPOCHS + 1
):
    train_loss, train_accuracy = train_one_epoch(
        model,
        train_loader
    )

    validation_loss, validation_accuracy = (
        evaluate_model(
            model,
            validation_loader
        )
    )

    history["train_loss"].append(
        train_loss
    )

    history["train_accuracy"].append(
        train_accuracy
    )

    history["validation_loss"].append(
        validation_loss
    )

    history["validation_accuracy"].append(
        validation_accuracy
    )

    is_better = (
        validation_accuracy
        > best_validation_accuracy
        or (
            validation_accuracy
            == best_validation_accuracy
            and validation_loss
            < best_validation_loss
        )
    )

    if is_better:
        best_validation_accuracy = (
            validation_accuracy
        )

        best_validation_loss = (
            validation_loss
        )

        best_epoch = epoch

        best_model_state = copy.deepcopy(
            model.state_dict()
        )

    print(
        f"Epoch {epoch:>2d}/{NUMBER_OF_EPOCHS} | "
        f"Train Loss {train_loss:.4f} | "
        f"Train Accuracy {train_accuracy:.4f} | "
```

## 실습 5-1 2픽셀 이동 민감도

실습 4-5와 **똑같은 실험**을 CNN에 합니다. 원본을 오른쪽으로 2픽셀 밀고, 새로 생긴 왼쪽은 0으로 채웁니다.

코드 박스: code/ch05_1_fashion_mnist_cnn_training_evaluation.py · CODE 30 · 실행 확인

```python
def shift_right(
    images,
    pixels=2
):
    shifted = torch.zeros_like(
        images
    )

    shifted[
        :,
        :,
        :,
        pixels:
    ] = images[
        :,
        :,
        :,
        :-pixels
    ]

    return shifted
```


코드 박스: code/ch05_1_fashion_mnist_cnn_training_evaluation.py · CODE 31 · 실행 확인

```python
shifted_correct = 0

prediction_changed = 0

total = 0

model.eval()

with torch.no_grad():
    for images, labels in test_loader:
        images = images.to(device)
        labels = labels.to(device)

        shifted_images = shift_right(
            images,
            pixels=2
        )

        original_predictions = model(
            images
        ).argmax(dim=1)

        shifted_predictions = model(
            shifted_images
        ).argmax(dim=1)

        shifted_correct += (
            shifted_predictions == labels
        ).sum().item()

        prediction_changed += (
            shifted_predictions
            != original_predictions
        ).sum().item()

        total += labels.size(0)

shifted_accuracy = (
    shifted_correct / total
)

prediction_change_rate = (
    prediction_changed / total
)

accuracy_drop = (
    test_accuracy - shifted_accuracy
)

print(f"원본 정확도: {test_accuracy:.4f}")
```

⟪box:결과 읽기 — 강의 4장 슬라이드 23의 답⟫

| 항목 | MLP (실습 4-5) | CNN (실습 5-1) |
|---|---|---|
| 원본 정확도 | 0.8848 | 0.8833 |
| 2픽셀 이동 정확도 | 0.5529 | **0.7471** |
| 정확도 감소 | 0.3319 | **0.1362** |
| 예측이 바뀐 비율 | 0.4213 | **0.2164** |

- 원래 정확도는 거의 같은데, 이미지를 옮기자 CNN의 정확도 감소는 MLP의 **절반이 안 됩니다**(33%p → 14%p).
- 같은 3×3 필터가 모든 위치를 훑으므로, 모양이 옮겨 가도 특징맵에서 그 모양이 **함께 옮겨 갈 뿐** 사라지지 않습니다. Max pooling은 작은 이동을 한 번 더 흡수합니다.
- 그래도 14%p나 떨어집니다. 마지막 `Linear(784, 10)`은 여전히 위치마다 다른 가중치를 쓰고, 7×7까지 줄어든 특징맵에서 2픽셀은 작은 이동이 아니기 때문입니다. 학습할 때 이미지를 조금씩 옮겨 보여 주는 **데이터 증강**이 이를 더 줄이는 방법입니다.

## 실습 5-2 계층별 출력을 모으는 함수

`model(image)`는 최종 로짓만 돌려줍니다. 중간 특징맵을 보려고 층을 하나씩 직접 통과시킵니다. `nn.Sequential`의 층 번호는 `model[0]` Conv1, `[1]` ReLU1, `[2]` Pool1, `[3]` Conv2, `[4]` ReLU2, `[5]` Pool2, `[6]` Flatten, `[7]` Linear입니다.

코드 박스: code/ch05_2_cnn_filter_feature_map_visualization.py · CODE 07 · 실행 확인

```python
def get_cnn_stages(model, images):
    conv1 = model[0](images)
    relu1 = model[1](conv1)
    pool1 = model[2](relu1)

    conv2 = model[3](pool1)
    relu2 = model[4](conv2)
    pool2 = model[5](relu2)

    flattened = model[6](pool2)
    logits = model[7](flattened)

    return {
        "conv1": conv1,
        "relu1": relu1,
        "pool1": pool1,
        "conv2": conv2,
        "relu2": relu2,
        "pool2": pool2,
        "logits": logits,
    }
```

```python
def show_example_features(
    model,
    example,
    title
):
    image, true_label, predicted_label = example

    image_input = image.unsqueeze(
        0
    ).to(device)

    with torch.no_grad():
        stages = get_cnn_stages(
            model,
            image_input
        )

    feature_maps = stages[
        "relu2"
    ].detach().cpu()

    scores = feature_maps[0].mean(
        dim=(1, 2)
    )

    top_channels = torch.topk(
        scores,
        k=3
    ).indices

    plt.figure(figsize=(10, 3))

    plt.subplot(1, 4, 1)
    plt.imshow(
        image.squeeze(),
        cmap="gray"
    )

        f"{title}\n"
        f"A:{class_names_ko[true_label]}\n"
        f"P:{class_names_ko[predicted_label]}"
    )
    plt.axis("off")

    for plot_index, channel in enumerate(
        top_channels,
        start=2
    ):
        plt.subplot(1, 4, plot_index)

        plt.imshow(
            feature_maps[0, channel],
            cmap="gray"
        )

        plt.title(
            f"Conv2 Map {channel.item() + 1}"
        )

        plt.axis("off")

    plt.tight_layout()
    plt.show()
```

## 정리와 스스로 점검

| 주제 | 핵심 |
|---|---|
| 합성곱 | 3×3 필터를 옮기며 같은 자리끼리 곱해 더함 + 바이어스 → 특징맵 |
| 풀링 | 2×2에서 최댓값 하나, 크기 절반, 채널 수 그대로, 파라미터 없음 |
| 패딩·스트라이드 | 출력 = `$\lfloor (N - F + 2P)/S \rfloor + 1$`, padding=1·stride=1이면 크기 유지 |
| 채널 | 필터 모양 `[출력, 입력, 높이, 너비]`, 출력 채널 수 = 필터 수, 입력 채널별 결과를 더함 |
| 모양 | `[N, 1, 28, 28]` → `[N, 8, 14, 14]` → `[N, 16, 7, 7]` → 784 → 10 |
| 파라미터 | Conv는 이미지 크기와 무관(가중치 공유): 9,098개 vs MLP 235,146개 |
| MLP와 비교 | 정확도는 비슷(0.8833 vs 0.8848), 2픽셀 이동에 훨씬 강함(감소 14%p vs 33%p) |
| 해석 | 학습된 필터는 경계 탐지기, 깊은 층은 조합된 특징. 특징맵으로 오답의 근거를 짐작 |

1. 5×5 입력에 3×3 필터, 패딩 0, 스트라이드 1이면 출력 크기는? 패딩 1이면?
2. 32×32 입력, 5×5 필터, 패딩 2, 스트라이드 2의 출력 크기는?
3. `nn.Conv2d(3, 32, kernel_size=3)`의 학습 파라미터 수는?
4. `[N, 16, 7, 7]`을 Flatten한 뒤 `nn.Linear(?, 10)`의 입력 수는?
5. 2×2 영역 `[[1, 4], [3, 2]]`의 max pooling, average pooling 결과는?
6. MaxPool2d와 ReLU의 학습 파라미터 수는?
7. 이미지가 커져도 Conv 층의 파라미터 수가 그대로인 이유는?

정답: ① 3×3, 5×5 ② `$\lfloor (32 - 5 + 4)/2 \rfloor + 1 = 16$`, 16×16 ③ `$32 \times 3 \times 3 \times 3 + 32 = 896$` ④ 16×7×7 = 784 ⑤ 4, 2.5 ⑥ 둘 다 0개 ⑦ 같은 필터를 모든 위치에서 다시 쓰므로(가중치 공유) 파라미터는 필터 크기·채널 수로만 정해짐
